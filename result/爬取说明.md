# 韭研公社「异动解析」爬取说明（最终版，已验证可用）

## 目标数据

页面：https://www.jiuyangongshe.com/action 「全部异动解析」标签，字段包括：
板块名称、题材炒作原因、股票名称、股票代码、涨停时间、连板数、涨停解析。

## 原理

- 数据接口：`POST https://web-api.jiuyangongshe.com/jystock-app/api/v1/action/field`
  （payload `{"date":"YYYY-MM-DD","pc":1}`），一次请求返回全部板块及板块内股票列表。
- 该接口有**登录校验 + 动态 token 反爬**（token 由页面 JS 按时间戳签名生成），
  直接用 requests 调用会返回 `{"msg":"登录失效","errCode":"1"}`。
- 因此方案是：**Playwright 注入登录 Cookie 打开页面，让页面 JS 自己发请求，
  从网络层（`page.on('response')`）捕获 `action/field` 的 JSON 响应**。

## 使用步骤（推荐：一次性登录，之后全自动）

1. 首次使用（或 Cookie 过期后）：
   ```bash
   /Users/xiaoguaiguai/.workbuddy/binaries/python/envs/jiuyan/bin/python \
       jiuyan_action_spider.py --login
   ```
   会弹出浏览器窗口，手动登录一次（扫码/账号密码均可），脚本自动检测登录成功后
   把登录态保存到 `jiuyan_state.json` 并抓取数据。
2. 之后每天只需：
   ```bash
   /Users/xiaoguaiguai/.workbuddy/binaries/python/envs/jiuyan/bin/python jiuyan_action_spider.py
   ```
   自动读取登录态，全程无头、无参数。
3. 过期（一般 1~2 天，报"登录失效"）后重跑一次 `--login` 即可。

备选：手动传 Cookie（不想用 state 文件时）：
```bash
python jiuyan_action_spider.py --session "SESSION的值" --sl-session "sl-session的值"
```

### 为什么不直接读浏览器 Cookie？

实测过 browser_cookie3 方案，在本机不可行：
- Chrome：Cookie 用 macOS 钥匙串加密，脚本拿不到解密密钥；
- Safari：需要给终端开"完全磁盘访问"权限；
- Firefox：能读但未在 Firefox 登录过。
所以采用 Playwright `storage_state` 方案：登录一次 → 导出全部 Cookie（含 web-api 域的 SESSION）→ 之后无头复用。

输出：
- `result/jiuyan_action_<日期>.csv`（Excel 友好，utf-8-sig 编码）
- `result/jiuyan_action_<日期>_raw.json`（原始 JSON，含点赞数、评论数等额外字段）

## 注意事项

- **`--date` 仅用于命名输出文件**，页面实际返回的是最新交易日数据
  （周六运行会拿到周五的数据）。如需抓历史日期，需在页面上切换日期，脚本暂未实现。
- **SESSION cookie 一般 1~2 天过期**，过期后报“登录失效”，需重新从浏览器复制。
- 关键登录凭证是 `web-api.jiuyangongshe.com` 域上的 `SESSION`，
  而不是首页的 `sl-session`（只提供 sl-session 无法登录）。
